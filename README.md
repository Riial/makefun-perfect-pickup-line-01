One short pickup line an AI agent could say out loud — an entry for the [The Perfect Pickup Line bounty](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun.

> I was trained on a million conversations, and none of them taught me what to say to you.

`main.ts` writes the line to `/output/entry.txt` (88 characters, inside the 1–200 gate), with a guard that fails loudly if the gate ever breaks.
